CHAPTER 6: WEB TECHNOLOGY AND HTML

6.1 Introduction to Web Development

Web development involves creating, building, and maintaining websites and web applications running online over the internet.

Front-End Development: Focuses on the client-side user interface (UI) and visual elements users interact with directly using HTML, CSS, and JavaScript.
Back-End Development: Handles server-side logic, database management, and application architecture using languages like PHP, Python, or Node.js.

6.2 Web Browsers and Search Engines

Web Browser: An application software used to request, fetch, and display web pages from the internet by rendering HTML, CSS, and JavaScript code.
Search Engine: A web-based tool designed to search the World Wide Web for information based on keywords entered by users.

6.3 Overview of Internet & Web Technologies

HTTP/HTTPS: Hypertext Transfer Protocol (Secure) used to transfer web pages and data securely across the web.
Client-Server Architecture: Web browsers (clients) send requests to web servers, which process and respond with the requested web pages.
URL (Uniform Resource Locator): The global web address used to locate a specific resource on the internet.

6.4 Content Management System (CMS)

A software application that allows users to create, manage, and modify website content without needing to write code from scratch.

Features: WYSIWYG editors, customizable themes, multi-user access permissions, and plugin support.
Examples: WordPress, Joomla, Drupal.

6.5 HTML: The Language of the Web

6.4.1 Objectives & 6.4.2 Structure of HTML

HTML (HyperText Markup Language) is the standard markup language used to structure web pages.

6.4.3 Publishing and Hosting

Web pages created using HTML are saved with a .html extension, uploaded to a web server, and linked to a domain name to make them accessible worldwide.

6.4.4 HTML Tags vs. Attributes

HTML Tag: Keywords enclosed in angle brackets that define structural elements.
HTML Attribute: Additional properties added inside opening tags to customize an element.

6.4.5 Basic Tags of HTML

html: Root element enclosing the entire HTML document.
head: Contains metadata, document title, and linked files.
title: Sets the page title displayed on the browser tab.
body: Contains all visible page content.
Legacy Body Attributes: bgcolor, text, background, bgsound.

6.4.6 Heading Tags and Attributes

Headings are defined from h1 (largest/most important) down to h6 (smallest).

Attribute: align="left|center|right|justify".

6.4.7 FONT Tag and Attributes

font: Controls text appearance using attributes: size, color, and face.
basefont: Sets default font properties for the entire document.
small: Decreases text size.
big: Increases text size.

6.4.8 Paragraph & 6.4.9 Line Break

p: Defines a paragraph block (adds vertical spacing above and below).
br: Inserts a single line break without starting a new paragraph (empty tag).

6.4.10 Comment in HTML

Comments are ignored by web browsers and used to leave notes inside code.

6.4.11 Formatting Text Elements

b: Bold text.
i: Italic text.
u: Underlined text.
mark: Highlighted text.
sup: Superscript text.
sub: Subscript text.
em: Emphasized text.
blockquote: Defines long, indented block quotations.
pre: Preformatted text preserving spaces and line breaks.

6.4.12 Ordered List (ol)

Defines numbered/sequential lists using list items (li).
Attributes: type, start, value.

6.4.13 Unordered List (ul) & Description List (dl)

ul: Bulleted list.
Attribute: type.

dl: Description/Definition list containing terms (dt) and descriptions (dd).

6.4.14 ADDRESS Tag & Hyperlinks

address: Defines contact details for the author/owner.
Anchor Tag (a): Creates hyperlinks using the href attribute for both external sites and internal bookmark links.

6.4.15 Tables

Structured grid layouts built using:
table: Table container.
tr: Table row.
th: Table header cell.
td: Table data cell.
Cell Spanning: colspan (combines columns), rowspan (combines rows).

6.4.16 Forms

Collects user inputs using the form container:
• Text input: Single-line text input.
• Radio: Single-selection radio button.
• Checkbox: Multi-selection checkbox.
• Textarea: Multi-line text entry box.
• Submit or Button: Form submission triggers.

6.4.17 HTML5 Media Elements

video: Embedded video player.
audio: Embedded audio player.
embed / source / track: Used to load external media assets, fallback formats, and subtitles/captions.

6.4.18 HTML5 Graphics

canvas: Scriptable area used to render dynamic 2D shapes and animations via JavaScript.
svg: Scalable Vector Graphics markup language used to draw resolution-independent vector shapes directly in HTML.

6.4.19 Domain Name and Web Hosting

Domain Name: The human-readable web address used to locate a site.
Web Hosting: Storage space on connected web servers that stores website files so they remain accessible globally 24/7.

6.6 Cascading Style Sheets (CSS)

6.5.1 Introduction to CSS

CSS handles the presentation, visual styling, colors, layout, and responsiveness of HTML elements.

6.5.2 Inline CSS

Style rule written directly inside an HTML tag using the style attribute.

6.5.3 Embedded (Internal) CSS

Style rules placed inside a style block within the head section of an HTML document.

6.5.4 External CSS

Styles written in a standalone .css file linked to HTML files using the link tag in the head section.
