CHAPTER 3: COMPUTER SOFTWARE AND OPERATING SYSTEM

3.1 Concept of Software

3.1.1 Definition of Software

A collection of instructions, data, or programs used to operate computers and execute specific tasks. It acts as the interface between the human user and the computer hardware.

3.1.2 Categories of Software

System Software: Controls hardware operations and provides a platform for running application software (e.g., Operating Systems, Device Drivers).
Utility Software: Helps analyze, configure, optimize, or maintain a computer system (e.g., Antivirus, Disk Defragmenter, Compression tools).
Application Software: Designed for end-users to perform specific tasks (e.g., MS Word, Photoshop, Web Browsers).
Web-Based Applications: Programs hosted on a remote server and accessed through a web browser over the Internet (e.g., Google Docs, Canva).
Mobile Apps: Applications designed specifically for mobile devices like smartphones and tablets (e.g., WhatsApp, eSewa).

3.2 Concept of Operating System

3.2.1 Introduction to Operating System

An Operating System (OS) is system software that acts as an intermediary between computer users and computer hardware. It manages hardware resources and provides a user-friendly environment for running application software.

3.2.2 Role of Operating System

• Acts as a Resource Manager (allocates CPU time, memory, and devices).
• Serves as an Interface Provider between user and hardware.
• Functions as an Environment Creator for program execution.

3.2.3 Functions of an Operating System

Process Management: Schedules, creates, and terminates processes.
Memory Management: Allocates and deallocates primary memory space to programs.
File Management: Organizes, creates, deletes, and secures files and directories.
Device Management: Controls input/output devices using specialized drivers.
Security & Protection: Protects user data via authentication and permission controls.
User Interface: Provides CLI (Command Line Interface) or GUI (Graphical User Interface).

3.2.4 Operating System Terminology

Multiprogramming: Keeps multiple programs in main memory simultaneously so the CPU can switch between them, maximizing CPU utilization.
Multitasking: Allows a user to execute multiple tasks concurrently on a single CPU by rapidly switching between them (time-sharing).
Multiprocessing: Uses two or more physical CPUs within a single system to execute multiple instructions simultaneously.
Distributed OS: Runs across multiple independent computers connected over a network, treating them as a single cohesive system.

3.3 Windows Operating System

3.3.1 Introduction to GUI-Based Operating System and Its Features

A Graphical User Interface (GUI) OS allows users to interact with the system using visual elements like icons, windows, menus, and pointers instead of typing text commands.

Key Features: Intuitive icons, plug-and-play support, multitasking capabilities, visual file management, and mouse/touch navigation.

3.3.2 Working in Desktop Application and Window Environment

Desktop Components: Taskbar, Start Menu, System Tray, Desktop Shortcuts.
Window Elements: Title Bar, Menu Bar, Minimize/Maximize/Close Buttons, Scrollbars, and Workspace area.

3.3.3 Manage Files and Folders with File Explorer

File Explorer: Windows utility used to view, navigate, and organize files and folders.
Core Operations: Creating, renaming, copying, moving, deleting, restoring from Recycle Bin, and searching for files.

3.3.4 Customize the Start Screen and Desktop

• Personalizing themes, wallpapers, and screen savers via Settings.
• Pinning/unpinning apps to the Start Menu or Taskbar.
• Adjusting display resolution and scaling.

3.3.5 Installing and Removing Devices

Plug and Play (PnP): Automatic driver detection and setup when connecting peripherals.
Device Manager: System tool used to view, update, disable, or uninstall hardware drivers manually.

3.3.6 Manage Passwords and Privacy Levels

• Setting local account passwords, PINs, or biometric sign-ins (Windows Hello).
• Configuring app permissions (location, camera, microphone) under Privacy & Security settings.

3.3.7 Use of Control Panel, System Tools, and Accessories

Control Panel: Centralized hub for administrative settings (User Accounts, Administrative Tools, Program Management).
System Tools: Disk Cleanup, Defragment and Optimize Drives, System Information, Task Manager.
Accessories: Pre-installed tools like Notepad, Paint, Calculator, and Snipping Tool.

3.4 Open Source and Mobile Operating System

3.4.1 Concept of Open Source Operating System

An OS whose source code is released under a license that allows anyone to inspect, modify, enhance, and distribute it freely without licensing fees (e.g., Linux).

3.4.2 Introduction to Linux and UNIX

UNIX: A powerful, multi-user, multitasking OS developed in the late 1960s at AT&T Bell Labs. Proprietary and widely used in enterprise servers.
Linux: A free, open-source Unix-like OS kernel created by Linus Torvalds in 1991. Highly secure, stable, and flexible.

3.4.3 Linux Distributions

A Linux distribution (Distro) combines the Linux kernel with system tools, GUI desktops, and package managers into a complete OS package.

Examples: Ubuntu, Fedora, Debian, Red Hat Enterprise Linux (RHEL), Kali Linux, Mint.

3.4.4 Concept of Mobile Operating System

An operating system designed specifically to power smartphones, tablets, and wearable devices. It handles wireless connectivity, touch input, power management, and mobile application frameworks.

3.4.5 Types of Mobile Operating System

Android: Google-owned, open-source OS based on the Linux kernel; powers the majority of global mobile devices.
iOS: Apple’s proprietary OS designed exclusively for iPhones.
Other Historical/Niche OS: Windows Phone OS, KaiOS (smart feature phones), BlackBerry OS.
