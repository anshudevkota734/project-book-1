CHAPTER 5: PROGRAMMING CONCEPTS AND C PROGRAMMING

5.1 Programming Concept

5.1.1 Introduction to Programming Languages

A programming language is a set of instructions, commands, and syntax used to create software programs and communicate with computers.

5.1.2 Low level, High level, 4 GL Programming Languages

Low-Level Languages: Machine-dependent languages that interact directly with hardware. Includes Machine Language (binary 0s and 1s) and Assembly Language (uses mnemonics).
High-Level Languages: Human-readable, machine-independent languages using English-like syntax (e.g., C, C++, Java, Python).
4GL (Fourth-Generation Languages): Non-procedural, declarative languages designed for database queries and rapid report generation (e.g., SQL).

5.1.3 Compiler, Interpreter and Assembler

Compiler: Translates the entire high-level source code into machine code at once before execution.
Interpreter: Translates high-level source code line-by-line and executes it immediately.
Assembler: Translates assembly language code into machine code.

5.1.4 Syntax, Semantic and Runtime Errors

Syntax Error: Occurs when programming rules or grammatical structures of the language are violated.
Semantic Error: Occurs when the code is syntactically correct but logically flawed, producing incorrect results.
Runtime Error: Occurs during program execution, causing crash or abnormal termination (e.g., division by zero).

5.1.5 Control Structures: Sequence, Selection and Iteration

Sequence: Default execution flow where statements execute line by line in order.
Selection: Conditional branching that executes specific blocks based on true/false evaluation.
Iteration: Repetitive execution of a block of code while a specified condition remains true.

5.1.6 Program Design Tools – Algorithm, Flowchart and Pseudocode

Algorithm: A step-by-step logical sequence of instructions written in plain plain language to solve a problem.
Flowchart: A graphical representation of an algorithm using standardized geometrical symbols.
Pseudocode: An informal, high-level description of an algorithm written in plain text structured like programming code.

5.1.7 Absolute Binary, BCD, ASCII and Unicode

Absolute Binary: Representation of numbers using pure binary values (base 2).
BCD (Binary Coded Decimal): Representation where each decimal digit (0-9) is encoded into a 4-bit binary sequence.
ASCII (American Standard Code for Information Interchange): A 7-bit or 8-bit character encoding system representing English characters and control symbols.
Unicode: A universal character encoding system capable of representing characters and symbols from all global languages.

5.2 C Programming Languages

5.2.1 Introduction and Features of C Language

C is a powerful, general-purpose, structured procedural programming language developed by Dennis Ritchie at Bell Labs in 1972.

Key Features: Portable, fast, efficient, modular, extensible, and supports low-level memory access using pointers.

5.2.2 Structure of C Program

A standard C program consists of documentation section, preprocessor directives, global declarations, main function, and user-defined sub-functions.

5.2.3 C Preprocessor and Header Files

C Preprocessor: A program that processes source code before compilation begins (e.g., #include, #define).
Header Files: Files containing predefined function declarations and definitions (e.g., stdio.h, math.h).

5.2.4 Character Set Used in C

The C character set includes uppercase and lowercase letters (A-Z, a-z), digits (0-9), special symbols (!, @, #, $, %, etc.), and white space characters.

5.2.5 Use of Comments

Comments are non-executable text used to document and explain code logic to programmers.
• Single-line Comment: Starts with double forward slashes.
• Multi-line Comment: Enclosed between forward slash-asterisk and asterisk-forward slash.

5.2.6 Identifiers, Keywords and Tokens

Token: The smallest individual element in a C program.
Keywords: Reserved words with fixed meaning defined by the C compiler (e.g., int, return, if).
Identifiers: User-defined names assigned to variables, functions, and arrays.

5.2.7 Basic Data Types in C

• int: Used to store integer values.
• float: Used to store single-precision floating-point numbers.
• double: Used to store double-precision floating-point numbers.
• char: Used to store single characters.

5.2.8 Constants and Variables

Variables: Named memory locations whose stored values can change during program execution.
Constants: Fixed values that cannot be modified during program execution.

5.2.9 Type Specifier

Format specifiers inform functions like printf and scanf about the type of data being read or written (%d for int, %f for float, %c for char, %s for string).

5.2.10 Simple and Compound Statements

Simple Statement: A single instruction ending with a semicolon.
Compound Statement: A group of simple statements enclosed within curly braces acting as a single block.

5.2.11 Operators and Expressions

Arithmetic Operators: Perform mathematical operations (+, -, *, /, %).
Relational Operators: Compare two values (>, <, >=, <=, ==, !=).
Logical Operators: Combine multiple condition evaluations (&&, ||, !).
Assignment Operators: Assign values to variables (=, +=, -=).
Unary Operators: Operate on a single operand (++ increment, -- decrement).
Conditional Operator: Ternary operator (condition ? true_value : false_value).

5.2.12 Input/Output (I/O) Functions

• Formatted I/O: printf (output) and scanf (input).
• Unformatted Character I/O: getchar, putchar, getch, getche.
• Unformatted String I/O: gets, puts.

5.2.13 Selection Control Statement: Decisions

• if Statement: Executes a code block if the condition evaluates to true.
• if-else Statement: Executes one block if true, and another block if false.
• if-else-if Ladder: Tests multiple conditional expressions sequentially.
• Nested if: An if statement placed inside another if statement.
• switch Statement: Evaluates an expression and branches to matching labeled case statements.

5.2.14 Iteration Control Statement: Looping

• while Loop: Entry-controlled loop that tests condition before execution.
• do-while Loop: Exit-controlled loop that executes at least once before testing condition.
• for Loop: Compact entry-controlled loop featuring initialization, condition, and increment/decrement.
• Nested Loop: Placing one loop inside the body of another loop.

5.2.15 Array

An array is a collection of fixed-size homogeneous elements stored in contiguous memory locations.

• 1D Array: A linear list indexed by a single subscript.
• 2D Array: A tabular grid consisting of rows and columns indexed by two subscripts.
• Matrix Operations: 2D arrays are used to perform matrix operations such as addition and subtraction by processing matching row-column elements.

5.2.16 String and String Functions

A string is a one-dimensional array of characters terminated by a null character ('\0').

Standard String Functions (string.h):
• strlen: Calculates and returns the character length of a string.
• strcat: Concatenates (appends) one string to the end of another.
• strcmp: Lexicographically compares two strings.
• strrev: Reverses the characters of a string in place.
• strcpy: Copies source string contents into a target string.
• strlwr: Converts all characters in a string to lowercase.
• strupr: Converts all characters in a string to uppercase.
