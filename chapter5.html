5.1 Programming Concepts & Logics5.1.1 Introduction to Programming LanguagesA programming language is a formal set of instructions used to communicate with a computer and develop software, applications, or systems.5.1.2 Categories of Programming LanguagesLow-Level Languages:Machine Language (1st Gen): Direct binary code ($0$s and $1$s) executed natively by hardware. Extremely fast, but machine-dependent.Assembly Language (2nd Gen): Uses short human-readable mnemonics (e.g., MOV, ADD) instead of binary. Requires an assembler.High-Level Languages (3rd Gen): Human-friendly, portable languages using English-like words and math symbols (e.g., C, C++, Java, Python).4th Generation Languages (4GL): Non-procedural languages focused on what output is needed rather than how to compute it (e.g., SQL, MATLAB).5.1.3 Language TranslatorsAssembler: Translates Assembly code into Machine code.Compiler: Translates an entire source program into machine code at once, generating an executable file before running (e.g., C, C++).Interpreter: Translates and executes source code line-by-line, stopping immediately when an error is encountered (e.g., Python).5.1.4 Types of Programming ErrorsSyntax Error: Violation of the programming language's grammar rules (e.g., missing semicolon ;). Caught during compilation.Semantic Error: Logic or structural misuse where code is syntactically valid but makes no logical sense to the compiler (e.g., $A + B = C$ instead of $C = A + B$).Runtime Error: Occurs while the program is running, often causing a crash (e.g., division by zero, accessing out-of-bounds memory).5.1.5 Control StructuresSequence: Instructions executed linearly, top to bottom.Selection (Branching): Chooses execution paths based on conditions (if, if-else, switch).Iteration (Looping): Repeats a block of code while a condition remains true (for, while, do-while).5.1.6 Program Design ToolsAlgorithm: A step-by-step, finite set of clear instructions written in plain language to solve a problem.Flowchart: A visual, graphical representation of an algorithm using standard shapes (ovals for start/stop, rectangles for processing, diamonds for decisions).Pseudocode: An informal, language-agnostic outline of code logic combining plain language with basic programming structures.5.1.7 Data Representation CodesAbsolute Binary: Direct representation of numerical values in pure binary ($0$ and $1$).BCD (Binary Coded Decimal): Encodes each individual decimal digit ($0–9$) into a 4-bit binary equivalent.ASCII: 7-bit or 8-bit character code standard representing text characters and control symbols (e.g., $'A' = 65_{10}$).Unicode: Universal multi-byte encoding system capable of representing text characters across almost all global languages and writing systems (e.g., UTF-8, UTF-16).5.2 C Programming Language5.2.1 Features of CCreated by Dennis Ritchie in 1972 at AT&T Bell Labs.High-speed execution, structured procedural approach, rich built-in library, portably hardware-accessible via pointers.5.2.2 Structure of a C ProgramC#include // Preprocessor directive int main() { // Main entry function // Statements printf("Hello, World!"); return 0; // Return statement } 5.2.3 C Preprocessor and Header FilesPreprocessor Directives: Commands evaluated before compilation starts, prefixed with # (e.g., #include, #define).Header Files: Files ending with .h that contain function prototypes and declarations (e.g., for I/O, for math routines).5.2.4 Character Set in CIncludes uppercase letters (A–Z), lowercase letters (a–z), digits (0–9), and special symbols (+, -, *, &, {, }, ;, etc.).5.2.5 CommentsNon-executable explanatory notes placed within code:Single-line: // commentMulti-line: /* comment */5.2.6 Tokens, Identifiers, and KeywordsTokens: The smallest individual building blocks of a C program.Identifiers: User-defined names given to variables, arrays, and functions.Keywords: Reserved words with fixed meanings in C (32 standard keywords like int, return, if, while).5.2.7 Basic Data Types in Cchar (1 byte): Stores single character.int (2 or 4 bytes): Stores whole numbers.float (4 bytes): Stores single-precision decimal numbers.double (8 bytes): Stores double-precision floating-point numbers.5.2.8 Constants and VariablesVariables: Named memory locations whose stored values can change during execution (e.g., int x = 5;).Constants: Fixed values that do not change during program execution (e.g., #define PI 3.14 or const int MAX = 100;).5.2.9 Format SpecifiersUsed in formatting input and output strings: %d (int), %f (float), %c (char), %s (string), %lf (double).5.2.10 Simple and Compound StatementsSimple Statement: A single executable line ending with a semicolon (e.g., x = 10;).Compound Statement (Block): A group of two or more simple statements enclosed within curly braces { ... }.5.2.11 Operators in CArithmetic: +, -, *, /, % (modulo)Relational: ==, !=, >, <, >=, <=Logical: && (AND), || (OR), ! (NOT)Assignment: =, +=, -=, *=, /=Unary: ++ (increment), -- (decrement), - (negation)Conditional (Ternary): condition ? expression1 : expression25.2.12 Input/Output (I/O) FunctionsFormatted: printf() (output), scanf() (input).Unformatted: getchar(), putchar(), gets(), puts().5.2.13 Selection Control StatementsC// Decision structures evaluate expressions to route execution: if (condition) { /* code */ } else if (condition) { /* code */ } else { /* code */ } // Multi-way branching using discrete values: switch(choice) { case 1: /* code */ break; default: /* code */ } 5.2.14 Iteration Control Statements (Loops)while loop (Entry-controlled): Checks condition before execution.do-while loop (Exit-controlled): Executes code block at least once before checking condition.for loop (Count-controlled): Combines initialization, condition, and increment/decrement in one line.5.2.15 Arrays (1D and 2D)An array is a collection of elements of the same data type stored in contiguous memory locations.1D Array: int numbers[5];2D Array: int matrix[2][3];Matrix Addition Example (Concept):Cfor(int i = 0; i < rows; i++) { for(int j = 0; j < cols; j++) { sum[i][j] = matrixA[i][j] + matrixB[i][j]; } } 5.2.16 String OperationsA string in C is a 1D array of characters terminated by a null character (\0).Common Functions:strlen(s) — Returns string length.strcpy(dest, src) — Copies src to dest.strcat(dest, src) — Appends src to end of dest.strcmp(s1, s2) — Compares two strings ($0$ if equal).strrev(s) — Reverses a string.strlwr(s) — Converts string to lowercase.strupr(s) — Converts string to uppercase.
