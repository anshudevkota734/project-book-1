CHAPTER 1: COMPUTER SYSTEM

1.1 Introduction of Computer

1.1.1 Definition, Characteristics, and Applications

Definition: An electronic device that accepts raw data as input, processes it according to stored instructions, and produces meaningful information as output.

Characteristics:
Speed: Executes millions of instructions per second (MIPS).
Accuracy: Produces error-free results (garbage in, garbage out principle).
Diligence: Works continuously without tiredness or boredom.
Versatility: Performs diverse tasks ranging from simple calculations to complex simulations.
Storage: Stores vast amounts of data in primary and secondary memory.

Applications: Used in Education, Healthcare, Banking, Scientific Research, Communication, and Entertainment.

1.1.2 Evolution of Computer Technology

Mechanical Era: Abacus, Pascaline, Difference Engine, and Analytical Engine (Charles Babbage - Father of Computing).

Generations of Computers:
1st (1940–1956): Vacuum Tubes | Magnetic Drums | Machine Language | ENIAC, UNIVAC
2nd (1956–1963): Transistors | Magnetic Core | Assembly Language | IBM 1401
3rd (1964–1971): Integrated Circuits (ICs) | Magnetic Disk | High-Level (FORTRAN, BASIC) | IBM 360
4th (1971–Present): Microprocessors (VLSI) | Semiconductor RAM/ROM | C, C++, Java, Python | PCs, Laptops
5th (Present & Beyond): Ultra Large Scale Integration (ULSI) / AI | High-Density Flash / Cloud | Natural Languages | Quantum / Supercomputers

1.1.3 Measurement Unit of Processing Speed and Storage Unit

Processing Speed:
Hertz (Hz): Clock cycles per second (Gigahertz - GHz is standard for modern CPUs).
MIPS: Millions of Instructions Per Second.
FLOPS: Floating-point Operations Per Second (used for supercomputers).

Storage Units:
8 Bits = 1 Byte
1024 Bytes = 1 Kilobyte (KB)
1024 KB = 1 Megabyte (MB)
1024 MB = 1 Gigabyte (GB)
1024 GB = 1 Terabyte (TB)
1024 TB = 1 Petabyte (PB)

1.1.4 Super, Mainframe, Mini, and Microcomputers

Supercomputer: Most powerful, fastest, and most expensive computers designed for complex scientific tasks (e.g., weather forecasting, nuclear research). Examples: Frontier, Fugaku.
Mainframe Computer: Large-scale computers designed to handle massive amounts of concurrent data and transactions for enterprise organizations (e.g., banks, airlines).
Minicomputer: Mid-sized multi-user computers used in medium enterprises or university departments.
Microcomputer: Compact, single-user computers driven by a microprocessor (e.g., desktops, laptops, tablets).

1.1.5 Mobile Computing and Its Applications

Definition: Technology that allows transmission of data, voice, and video via a computer or wireless-enabled device without fixed physical links.
Key Components: Mobile hardware (smartphones, tablets), mobile software (Android, iOS), and mobile communication (cellular networks, Wi-Fi).
Applications:
• Mobile banking and digital payments (e.g., eSewa, mobile banking apps).
• Navigation and GPS services.
• On-demand healthcare, education, and remote work communication.

1.2 Computer System and I/O Devices

1.2.1 Concept of Computer Architecture and Organization

Computer Architecture: Focuses on the conceptual design and functional structure visible to the programmer (e.g., instruction sets, addressing modes).
Computer Organization: Focuses on operational units and their interconnections that realize architectural specifications (e.g., clock signals, memory control circuits).

1.2.2 Components of Computer System

Input Unit: Converts user data into machine-readable format (e.g., Keyboard, Mouse).
Processing Unit (CPU): Executes instructions and controls operations.
Output Unit: Translates processed data into human-readable format (e.g., Monitor, Printer).
Memory Unit: Holds data and instructions currently in use (e.g., RAM).
Storage: Retains data permanently for future use (e.g., SSD, HDD).

1.2.3 Microprocessor: Basic Concepts

Definition: A single Integrated Circuit (IC) containing the complete Central Processing Unit (CPU) of a computer.

Components:
• Arithmetic Logic Unit (ALU): Performs mathematical operations and logical evaluations.
• Control Unit (CU): Directs and coordinates data flow between system components.
• Registers: High-speed internal temporary storage locations within the CPU.

Clock Speed: The speed at which a processor executes instructions, measured in Gigahertz (GHz).
Word Length: The number of bits a processor can process in a single instruction cycle (e.g., 32-bit, 64-bit).

1.2.4 Bus System

A collection of parallel wires transmitting signals between computer components.
Data Bus: Bi-directional lines carrying actual data between CPU, memory, and peripheral interfaces.
Address Bus: Uni-directional lines carrying memory addresses from CPU to system components.
Control Bus: Uni-directional/Bi-directional lines carrying control and timing commands from the CPU.

1.2.5 Primary Memory

Fast, volatile/non-volatile memory directly accessible by the CPU.

RAM (Random Access Memory): Volatile primary storage where active programs and data are temporarily kept.
• SRAM (Static RAM): Fast, expensive, uses flip-flops; used for Cache memory.
• DRAM (Dynamic RAM): Slower, cheaper, requires periodic refreshing; used as main memory.

ROM (Read-Only Memory): Non-volatile storage containing essential system startup routines (BIOS/UEFI).
• PROM: Programmable once by the user.
• EPROM: Erasable using ultraviolet light.
• EEPROM: Erasable electronically (foundation for modern flash storage).

Cache Memory: Extremely high-speed SRAM located on or near the processor to store frequently accessed data.
Buffer: Temporary holding area in memory used to compensate for speed differences between processing units and input/output devices.

1.2.6 Secondary Memory

Non-volatile, high-capacity, non-direct memory used for permanent storage.
Magnetic Disk: Uses magnetic patterns on spinning platters to store data (e.g., Hard Disk Drive).
Flash Memory: Solid-state non-volatile storage using electronic circuits with no moving parts (e.g., SSDs, Memory Cards).
Optical Disk: Uses laser beams to read/write data on reflective surfaces (e.g., CD, DVD, Blu-Ray).
External Storage Device & Memory Stick: Portable secondary storage media connecting via interfaces like USB.

1.2.7 Input Devices

Keyboard: Primary text-entry device.
Mouse: Pointing device used to interact with graphical interfaces.
Scanner: Converts physical documents and images into digital formats.
Light Pen: Photosensitive pen-like device used to draw directly on CRT screens.
OMR (Optical Mark Reader): Detects shaded marks on printed forms (used in multiple-choice exams).
OCR (Optical Character Recognition): Converts scanned physical text images into editable digital text.
BCR (Barcode Reader): Reads printed optical barcodes via light patterns.
MICR (Magnetic Ink Character Recognition): Reads special magnetic ink characters on bank checks.
Touch Screen: Input-output combined display that registers physical contact points.
Microphone: Converts audio sound waves into digital electrical signals.
Digital Camera: Captures and encodes optical images directly into digital media.

1.2.8 Output Devices

Monitors:
• LCD (Liquid Crystal Display): Uses liquid crystals modulated by light filters.
• LED (Light Emitting Diode): Uses semiconductor light diodes for higher contrast and energy efficiency.

Printers:
• Dot Matrix: Impact printer using physical pins striking an inked ribbon.
• Inkjet: Non-impact printer spraying microscopic liquid ink droplets.
• Laser: High-speed non-impact printer utilizing laser beams and electrostatic toner.

Speaker: Converts digital audio signals into audible sound waves.

1.2.9 Hardware Interfaces

Parallel Port: Legacy multi-pin interface transferring multiple bits simultaneously (traditionally used for printers).
Serial Port: Legacy interface transferring data sequentially one bit at a time.
USB Ports (Universal Serial Bus): High-speed standardized plug-and-play interface for connecting peripheral devices.
HDMI (High-Definition Multimedia Interface): High-bandwidth digital interface transmitting uncompressed video and multi-channel audio over a single cable.
Expansion Slots: Internal sockets on the motherboard used to install add-on cards (e.g., PCIe slots for graphics, network, or audio cards).
